# Project Statement

## Problem Statement
Managing student information manually can be difficult and time-consuming. This project provides a simple Java-based system to store, view, and search student information.

## Scope
The project covers basic management of student records, including adding student details, viewing student details, and searching for a student using their ID.

## Target Users
- Students
- Teachers
- Educational institutions

## High-Level Features
- Add student details
- View student records
- Search student by ID
- Simple menu-based interaction
