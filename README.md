# Student Management System

## Project Description
A simple Java-based Student Management System used to manage student information and marks.

## Features
- Add Student
- View Students
- Search Student
- Enter Marks
- Calculate Result
- Exit

## Technologies Used
- Java
- Java Scanner
- Object-Oriented Programming

## Files
- Main.java – Main program and menu
- Student.java – Stores student details
- StudentManager.java – Manages student records

## How to Run
1. Compile the Java files.
2. Run the Main class.
3. Select an option from the menu.
